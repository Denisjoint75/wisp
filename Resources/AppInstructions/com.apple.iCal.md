## Calendar

- Views: cmd+1 day, cmd+2 week, cmd+3 month, cmd+4 year; cmd+t today; cmd+r refresh.
- New event: cmd+n opens a quick-entry field; type a natural-language description (for example 'Lunch Friday 12pm') and press Return to create it. Double-click the event to open the editor: title and location are `field`s, dates and times are `datefield`/`timefield` controls (click a component such as hour or minute, type digits, Tab moves to the next component).
- Creating, editing or deleting events is an always-confirm action; the Delete key on a selected event removes it, so confirm first.
- Adding attendees sends invitations when the event is saved; confirm the attendee list before saving.
